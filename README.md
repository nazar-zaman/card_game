# Card Game (arcade)

This small project uses the `arcade` Python library for rendering a simple card game window.

If you see an ImportError for `arcade`, follow these steps from the workspace root:

1. Create and activate a virtual environment (optional but recommended):

```bash
python -m venv venv
source venv/bin/activate
```

2. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Run the app:

```bash
python "card game/main.py"
```

If a VS Code devcontainer or an existing virtual environment already exists at `venv/`, activate it before running step 3.
